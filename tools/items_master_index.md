# Items Master Sheet Index

Generated by `tools/build_items_master_sheet.py`. Open `assets/sprites/items_master.png` in any image editor; the cells listed below are painted, every other cell is transparent and free to use.

## How to read this file

- **Cell #** is the same as the item's `loy_tile_index`.
- Cells **0–255** live in rows 0–15 of the master (mirror of `tiles.png`).
- Cells **256–511** live in rows 16–31 (mirror of `tiles2.png`).
- Cells **512–1023** are rows 32–63 — **all empty, all yours**. Paint a new sprite into any free cell and set the item's `loy_tile_index` to that cell number.

To find a sprite by name, ⌘F this file.
