## How To Use The Graph

1. Open this note.
2. Open local graph first.
3. Expand into related system notes.
4. From system notes, move into generated file notes.

Use graph view for:

- architecture orientation
- high-level file clusters
- tracing which hub files belong to which subsystem

Do not use graph view as proof of real runtime behavior.
