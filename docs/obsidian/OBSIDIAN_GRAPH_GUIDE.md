# Obsidian Graph Guide

## Why The Graph Felt Huge

Because the vault still contains many notes, and global graph tries to show all of them at once.

That is normal.

## Best Way To Use It

Use `Local Graph`, not `Global Graph`, for day-to-day reading.

Open one of these first:

- [[START_HERE]]
- [[GRAPH_HOME]]
- [[system_overworld]]
- [[system_battle_rts]]
- [[file_game_manager.gd]]

## Built-In Filters

The repo graph preset is now tuned for:

- only `docs/obsidian`
- no orphans
- color groups by system/path

If Obsidian still shows the old giant graph:

1. close the graph tab
2. reload or reopen the vault
3. reopen graph view

## Recommended Graph Searches

For systems only:

```text
path:"docs/obsidian/systems"
```

For battle files only:

```text
path:"docs/obsidian/files/scripts/battle"
```

For overworld only:

```text
path:"docs/obsidian/files/scripts/overworld"
```

For hub files:

```text
file:HUBS OR file:GRAPH_HOME OR file:SYSTEMS_INDEX
```

## Best View Modes

- `Global Graph` for high-level architecture only
- `Local Graph` for actual reading
