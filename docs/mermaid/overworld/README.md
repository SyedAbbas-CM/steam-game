# Overworld Pack

This pack documents the overworld as a system shell.

It focuses on:

- overworld scene and script entrypoints
- chunk and zone loading
- player, HUD, inventory, and quest wiring
- war table, world map, territory attack, and fast travel flow
- the bridge from overworld into RTS battle
